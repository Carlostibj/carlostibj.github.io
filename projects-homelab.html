TROUBLESHOOTING · root cause & fixes

Troubleshooting Journal

The failures were part of the project. These are the issues that forced me to understand the stack more deeply.

Duplicate Gateway Conflict

Solved

Proxmox bridges and OPNsense both owned the same .1 gateway addresses, causing intermittent connectivity. I converted the internal bridges to Layer 2 only and left routing exclusively to OPNsense.

ProxmoxLayer 2/3OPNsense

Marketing VLAN Parent Error

Solved

Marketing DHCP/connectivity failed because the VLAN interface was attached to the wrong OPNsense parent. Correcting the parent restored stable VLAN operation.

VLANsDHCPOPNsense

Cloned Windows Trust Failures

Solved

Cloned clients shared identity information and developed machine-account trust problems. I repaired secure channels, assigned unique hostnames, and documented Sysprep/generalization for future templates.

Active DirectoryWindowsSysprep

AD Dynamic RPC Rule

Solved

Group Policy updates stalled because the OPNsense port alias for dynamic RPC used the wrong range syntax. Correcting the alias restored immediate gpupdate processing.

GPORPCFirewall

OPNsense GUI Lockout

Recovered

A broad private-network block also denied the IT workstation access to the firewall GUI. I recovered through the console and added an explicit management allow above the deny rule.

Firewall OrderManagement PlaneRecovery

Wazuh Storage Exhaustion

Solved

The Wazuh installation failed because Ubuntu's root logical volume used only part of the virtual disk. I expanded the LVM filesystem and completed the deployment.

UbuntuLVMWazuh
