How I work

Every project follows the same loop.

I don't count a project as done when the tool is installed. It's done when I can show it works, show where it doesn't, and explain it to someone else.

  1. PlanDefine the risk, the question an analyst needs answered, and the tests.
  2. BuildConfigure it in the lab, snapshot first.
  3. ValidateProve it fires, and prove the quiet cases stay quiet.
  4. DocumentEvidence, troubleshooting, limits, and lessons.
  5. PublishCase study page plus a full PDF report.
